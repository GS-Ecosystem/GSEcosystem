Information about the Application

GS HTTP — this is a lightweight and fast utility, specifically developed for web developers, system administrators, and everyone who works with APIs and network requests.
With GS HTTP you can:

• Instantly check the HTTP status of any website (200 OK, 404 Not Found and others).

• View server responses including body, headers, and cookies

• Open verified websites in the browser.

In this application, all necessary settings for usage are collected:

Network and Connection:
• Auto-redirect - a toggle that follows site redirects.
• Request Timeout - the ability to set the request time up to 30 seconds
Security and SSL:
• Check SSL - a toggle with strict certificate verification
• Ignore SSL errors - a toggle with self-signed certificates
User-Agent - by default, the user-agent is used in HTTP/1.1 even though it's not mandatory, but it's available in the application settings.
Personalization and Input:
Theme - the ability to change the application theme to light, dark, or system default
Language - the application is translated and available in two languages: English and Russian
Clear History and Input - allows clearing the history and current input in the scanner menu within the application.

In this application, there is also a history:
• It is saved in an isolated secure folder on Android, which does not require storage permission
• The history does not save many requests; instead, it overwrites old ones.
• It is unique in that it is stored locally on the user's device, and the application has no servers for storage and does not share it with third parties.

In this application, all 9 popular methods are available:
GET, POST, HEAD, PUT, PATCH, DELETE, CONNECT, TRACE, OPTIONS

Minimum Android version: Android 7
Download the application in two stores for Android applications: RuStore, APKPure

Search by URL

Now we will consider the first work of the application, how to check a specific website for availability and get additional details. It is important to correctly understand the concept of the application itself.
To perform the first URL check, you need to enter it first, for example, we enter the main site of the GS project -> https://gs-ht.ru.
Then we click the "Run Scan" button and see the response.
The data we enter is saved in the search history, where we can also track everything we have entered.
The search history is stored locally on the Android device and is not shared with third parties.
Additionally, when there is a successful response, you can open the website in the browser by clicking the "Open in Browser" button or view its content by clicking the "Search by Response Data" button.

Server Response Data

As already mentioned earlier, after a successful request, you can view the server's response data by clicking the "Search by Response Data" button.
In this window, you can switch between different types of data:
Body - The body of the website
Headers - The headers of the website.
Cookies - The cookies of the website.
Additionally, you can perform a search to find a specific tag or function.

Application Settings

Here are the settings for the entire application:
Network
Auto-redirect - redirects to a secure connection with 3xx codes.
Appearance and Data
Theme - changes the theme to "dark", "light", or "system".
Clear History and Input - clears the last input and history in the application.

Common Error

Here I want to point out just one mistake that can occur with many users when using the application.
This error is related to incorrectly entered URLs in the "Search by URL" menu, for example such as https: //gs-ht.ru or such as https:/gs-ht.ru.
It seems like a simple typo or missing slash that causes this error.
After you press the "Run Scan" button, the application will crash, but it's normal and you will be able to restart it. The error occurs because the application currently lacks proper error handling, but it will be added soon and will simply display an incorrect input format.
