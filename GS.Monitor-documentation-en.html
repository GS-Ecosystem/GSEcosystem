Introduction

GS.Monitor - powerful HTTP traffic analysis/analogue of the android application GS.HTTP
GS.Monitor(hereafter - the application) checks websites for their availability and also finds them by the entered value.
System requirements for different types of installations:
Windows: 7/10/11 !> 150MB
Linux/Debian/Ubuntu: 11/12 !> 70MB

Installation

You can download the application from GitHub in the Releases section of the repository

Important there will be one version for downloads, but there will be many files to help you navigate and not get confused during installation, I recommend familiarizing yourself with the files for each operating system:
.msi - Windows
.exe - Windows
.deb - Linux/Debian
.zip - Source code Windows/Portable version
tar.gz - Source code Linux

Launching the Application

After installing the application, you can immediately launch it without any additional settings or components required for its operation.

Search by URL

Currently we will consider the first work of the application, how to check a specific website for its availability and find out additional details. It is important to correctly grasp the concept of the application itself.
To conduct the first URL check, you need to enter it first, for example, we enter the main project website GS -> https://gs-ht.ru.
Then we click the "Run Scan" button and see the response.
The data we entered is saved in the search history, where we can also track everything we entered.
The search history is stored locally on the computer and is not shared with third parties.

Search by Matches

The application also has a "Search by Matches" menu, whose main task is to find a specific website by the name of any word. This is quite simpler than the URL scan panel.
Here you just need to enter the website name, for example, the same website but without the https:// prefix and its domain .ru.
Then we click "Find Matches" and see the response.

Search History

The data we entered is saved in the search history, where we can also track everything we entered.
The search history is stored locally on the computer and is not shared with third parties.

Application Settings

Here are the settings for the entire application:
Network
Request timeout - sets a specific time interval before a request is made 5/10/15 seconds.
Auto-redirect - redirects based on 3xx codes to a secure connection.
Security
SSL Security, which shows the SSL status.
Appearance and Data
Theme - changes the theme to "dark", "light", or system default.
Clear History and Input - clears the last input and history in the application.
