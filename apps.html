GS | Приложения

Проекты экосистемы GS имеют открытый исходный код для свободного аудита безопасности и полностью соответствуют официальным сборкам.

GS.HTTP

Android 7+

GS HTTP — это легковесная и быстрая утилита, разработанная специально для веб-разработчиков, системных администраторов и всех, кто работает с API и сетевыми запросами.

  • Поддержка 9 методов: GET, POST, PUT, DELETE и др.
  • Просмотр статуса ответа, заголовков, тела и куки
  • Гибкая настройка таймаутов, SSL и User-Agent
  • Локальная история запросов без отправки на сервер
Стек: Kotlin • Лицензия: MIT License

GS.HTTP

Windows / Linux

Минималистичный десктопный инструмент для анализа HTTP-трафика, отладки API и контроля сетевых взаимодействий на ПК.

  • Мгновенная проверка HTTP-статусов и заголовков
  • Удобное форматирование и чтение JSON-ответов
  • Анализ файлов cookie и поиск доменов
  • Локальное хранение истории без телеметрии
Стек: Kotlin / Jetpack Compose • Лицензия: MIT License
