GS.HTTP

Android 7.0+

GS HTTP is a lightweight and fast utility designed specifically for web developers, system administrators, and anyone working with APIs and network requests.

  • Supports 9 HTTP methods: GET, POST, HEAD, PUT, etc.
  • Inspect HTTP status codes, headers, response body, and cookies
  • Flexible timeout, SSL verification, and User-Agent settings
  • Local request history with no external servers or data collection
Stack: Kotlin • License: MIT License

GS.Monitor

Windows / Linux

A minimalist desktop tool for analyzing HTTP traffic, debugging APIs, and inspecting network interactions on PC.

  • Instant HTTP status and technical response header checks
  • Clean JSON data formatting and readability
  • Cookie inspection and domain lookup
  • Local request history with zero telemetry
Stack: Kotlin / Jetpack Compose • License: MIT License
